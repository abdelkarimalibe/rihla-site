Data sources and setup

Excel. The workbook is the pipeline. Export it, edit the Deals, Commitments and Calls sheets in Excel, then import it back. It is stored in this browser only and never uploaded.

Gmail and Google Calendar. Read-only, and only in your browser. One-time setup:

  1. In Google Cloud Console, create a project and enable the Gmail API and the Google Calendar API.
  2. Google Auth Platform: audience External, keep it in Testing, and add your own Gmail address as a test user.
  3. Create an OAuth client of type Web application. Authorised JavaScript origin:
  4. Paste the client ID into sales-config.js as SALES_GOOGLE_CLIENT_ID and redeploy.
  5. Press Connect Google. Access lasts about an hour, then press it again.

With Google connected the panel reads today's calendar, recent email with the contacts in your workbook, and promises in your sent mail to them. Nothing else is read and nothing is stored.
